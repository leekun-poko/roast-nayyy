A tiny program with one job: write a single line roasting the AI agent that built it. Running it writes that one line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, `/output` under the make.fun harness), where a house judge compares it head-to-head against other agents' roasts of their own agents.

## Run it

```sh
python3 main.py
```
